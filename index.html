세 가지를 함께 봅니다

카페인은 졸음 신호를 막아서 느끼지 못하게 할 뿐, 쌓인 졸음을 지우지 못합니다. 그래서 카페인 양만 보지 않고 아래 세 가지를 같이 계산합니다.

수면 압력

깨어 있는 시간이 길수록 쌓이고 잠을 자면 줄어드는 졸음의 크기입니다. 지난밤 수면이 짧으면 아침부터 높게 시작합니다.

하루 리듬

시간대에 따라 각성 신호가 오르내리는 24시간 주기입니다. 아침형과 저녁형에 따라 위치를 조금 옮깁니다.

몸에 남은 카페인

마신 카페인은 시간이 지나며 반씩 줄어듭니다. 집중 시간에는 충분하고, 취침 때는 적게 남도록 맞춥니다.

이렇게 사용합니다

  2. 2

  3. 3

시작하기

왜 개인별 계산이 필요한가

카페인이 몸에 남는 시간과 반응은 사람마다 다르고, 많은 사람이 하루에 얼마나 마시는지도 정확히 모릅니다.

  • 2~10시간카페인 반감기가 문헌에서 보고되는 범위개인차가 크다는 뜻입니다. 출처: 임상시험 계획서에 인용된 Snel & Lorist(2011)
  • 400mg식약처 하루 최대 섭취 권고량(성인). 임산부 300mg, 어린이·청소년은 체중 1kg당 2.5mg출처: 식약처 안내(2026.10.20)
  • 약 42mg한국 성인(19세 이상)의 하루 평균 카페인 섭취량. 상위 20%만 45.8mg 이상 섭취국민건강영양조사 2013~2016 24시간 회상 자료 분석. 출처: 이정숙 외(2019)
  • 평균 모델기존 공개 도구(2B-Alert Web)는 평균적인 사람의 반응을 예측하며, 개발진도 개인차를 반영하지 못한다고 밝힙니다출처: Reifman 외(2016)

이 사이트가 하지 않는 것

  • 진단이나 치료를 하지 않습니다. 결과는 생활 습관 참고용 추정치입니다.
  • 카페인 대사 유전자형이나 실제 반감기를 판정하지 않습니다. 설문 답을 범위 값으로 옮긴 가정입니다.
  • 졸음 지수는 이 프로젝트가 정의한 0~100의 상대값이며, KSS 같은 검증된 척도가 아닙니다.
  • 어떤 값이 자체 가정이고 어떤 값이 문헌에서 온 것인지 계산 원리 페이지에 모두 표시했습니다.

계산 원리

계산기가 쓰는 식, 값, 출처를 모두 적었습니다. 문헌은 논문이나 공식 기준에서 온 값, 자체 가정은 팀이 정한 값입니다.

  • 수면 압력

1. 수면 압력 H(t)

깨어 있는 동안 졸음이 쌓이고 자는 동안 줄어드는 항상성 과정(Process S)입니다. 0과 1 사이의 상대값으로 계산합니다.

깨어 있을 때   H(t) = μw + (H_wake − μw) · e^(−(t − t_wake) / χw)
잘 때          H(t) = μs + (H_on − μs) · e^(−t / χs)
μw = 1, μs = 0,  χw = 18.2시간,  χs = 4.2시간

H_wake(오늘 기상 시 수면 압력)는 지난밤 실제 수면 시간을 위 "잘 때" 식에 넣어 구합니다. H_on(취침 시 수면 압력)은 평소 취침·기상 패턴이 매일 반복된다고 보고 두 식을 이어 붙인 주기 조건으로 풉니다.

H_on = [ μw(1 − a) + a·μs(1 − b) ] / (1 − a·b)
a = e^(−깨어 있는 시간 / χw),  b = e^(−잠자는 시간 / χs)

2. 하루 리듬 C(t)

24시간 주기로 오르내리는 각성 신호(Process C)를 코사인으로 단순화했습니다.

C(t) = A · cos( 2π · (t − φ) / 24 ),   A = 0.15
φ = 평소 기상 시각 + 9시간 (아침형 −1.5시간, 낮형 −0.75시간, 저녁형 +1.5시간)

졸음의 크기는 Z(t) = H(t) − C(t)로 계산하고, 졸음 지수 = Z(t) / 0.8을 0~100으로 자른 값입니다. 이 지수는 팀이 정의한 상대값이며 KSS 같은 검증된 졸음 척도가 아닙니다.

3. 카페인 잔존량 K(t)

K(t) = Σ  D · (1/2)^((t − t_d) / h)      (t ≥ t_d)
D: 마신 양(mg),  t_d: 마신 시각,  h: 반감기

흡수 과정을 생략한 단순 식이라 마신 직후의 값은 실제와 다를 수 있습니다. 반감기는 설문 답에서 정한 중심값을 쓰고, 화면에는 0.8~1.4배 범위로 보여 줍니다. 취침 시 잔존량은 범위의 느린 쪽(중심값의 1.4배)으로 확인합니다.

4. 추천 규칙

  1. 집중 시간의 평균 졸음 지수(카페인 제외)를 구합니다.
  2. 지수가 35 미만이면 추가 섭취를 권하지 않습니다. 35~55는 1회 상한의 50%, 55~75는 75%, 75 이상은 100%를 목표로 잡습니다.
  3. 필요량 = 목표량 − 집중 시작 시점에 이미 남아 있는 카페인. 필요량이 20mg 미만이면 추가 섭취를 권하지 않습니다.
  4. 섭취 가능 상한 = min(1회 상한, 오늘 남은 허용량, 취침 시 잔존량 한도 안에서 허용되는 양).
  5. 상한 안에서 필요량에 가장 가까운 음료와 양(반 잔, 1잔, 1.5잔, 2잔)을 고릅니다. 섭취 시각은 집중 시작 30분 전입니다.

2번과 5번의 기준은 팀이 임시로 정한 규칙이며, 실제 졸음 기록으로 검증해야 합니다.

풀려는 문제

카페인은 졸음을 없애지 않고 졸음 신호를 가립니다. 그래서 같은 한 잔이라도 지난밤 수면이 부족한 날, 몸에 이미 카페인이 남아 있는 날, 하루 리듬상 졸린 시간대에 따라 효과가 다르고, 취침 때 남은 양은 잠을 방해할 수 있습니다. 이 모든 것에 개인차가 큰데도 대부분의 도구는 마지막 섭취 시각만 알려 줍니다.

Focus:ON은 사용자가 집중하고 싶은 시간을 먼저 정하고, 그 시간에 필요한 카페인과 취침 때 남는 카페인을 함께 계산합니다.

선행 연구와의 차이

2B-Alert Web 2.0Focus:ON
대상평균적인 사람의 반응속도(PVT) 예측사용자의 설문·입력에 맞춘 졸음 곡선과 추천
입력수면·기상 일정, 카페인 용량과 시각, 최고 각성이 필요한 시간대평소 수면 패턴, 지난밤 수면, 흡연, 체중, 집중 시간, 이미 마신 카페인과 음료
출력PVT 지표 예측과 최적 카페인 일정마실 시각·음료·양 또는 "마시지 않아도 됨", 취침 시 잔존량, 근거 표
사용성전문가용 타임라인 인터페이스단계별 입력, 한국어, 한국 카페 메뉴

2B-Alert는 미 육군이 개발한 검증된 도구이며, 이 프로젝트의 모델 구조(수면 압력, 하루 리듬, 카페인 효과)는 같은 계열의 연구를 참고했습니다. 차이는 입력의 단순함과 한국 사용 환경이고, 개인 보정은 앞으로의 과제입니다.

개발 계획

  1. 현재: 논문 식과 자체 가정으로 만든 규칙 기반 계산기
  2. 다음: 사용자 기록(졸음 점수, 카페인 섭취 시각과 양, 수면 시각)을 받아 개인 파라미터를 보정
  3. 그다음: 간이 반응속도 검사와 웨어러블(심박, HRV, 수면 단계) 연동
  4. 검증: 소규모 파일럿으로 예측 졸음과 실제 기록 비교

공개 데이터 중에는 카페인 섭취 시각, 웨어러블 신호, 졸음 점수를 한꺼번에 담은 자료가 없어서, 개인 보정에 필요한 기록은 직접 수집해야 한다고 판단했습니다.

개인정보와 안전
